# HarfChatBot

ربات پیام ناشناس تلگرام با Python + Flask + Webhook + Render

## امکانات
- لینک ناشناس اختصاصی
- ارسال پیام ناشناس
- دکمه پاسخ
- دکمه ری‌اکشن
- ذخیره در JSON
- ارسال فایل دیتابیس به گروه لاگ بعد از هر تغییر
- جایگزینی دیتابیس با آپلود فایل JSON توسط ادمین

## متغیرهای محیطی
- BOT_TOKEN
- BOT_USERNAME
- WEBHOOK_URL
- LOG_CHAT_ID
- ADMIN_ID
- PORT

## اجرا محلی
```bash
pip install -r requirements.txt
python app.py
